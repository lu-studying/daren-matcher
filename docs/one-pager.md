# 达人智能匹配工具 · 一页说明

## 解决谁的什么问题

中小品牌/机构的投放运营，拿到投放需求后需人工在数百达人中筛选，通常耗时 2-3 天，
且依赖个人经验、易漏易错。本工具将 brief 转化为带理由与风险的达人清单，2 分钟完成初筛。

**真实使用情况**（上线后回填）：
- 用户：__ 位投放/运营从业者
- 使用：__ 次搜索，__ 条推荐被采纳
- 对比：人工筛选约 __ 小时 → 工具 __ 分钟

## 实现方式

自然语言 brief
1. **解析**：通义千问抽取结构化需求（品类/平台/人群/预算/量级/风格）
2. **硬过滤**：预算、粉丝量级、品类用规则先行筛除，可解释且降低调用成本
3. **召回**：达人画像文本经 text-embedding-v3 向量化，FAISS 语义召回 Top50
4. **重排**：通义千问对候选逐个打分，强制输出 匹配理由 + 风险点
5. **反馈闭环**：采纳/不合适事件落库，驱动 Prompt 与数据迭代

**评测**：__ 条人工标注 brief，召回命中率 __%，重排 Top10 认可率 __%。

**一次错误修复实例**（体现对模型的理解，替换为你的真实案例）：
现象 → 原因（如粉丝量级未体现在画像文本，embedding 无法感知）→ 修复 → 指标变化。
